# Connections

参考了Tom McNamara 于 1991 年设计的双人抽象策略桌游《Connections》。
棋盘采用实体原版的 5 阶布局。

首页提供规则教学、双人热座和人机对战三个入口。规则教学复用真实棋盘与棋件效果，依次讲解普通落子、对边贯通、闭环胜利，最后通过两次点击演示金桥的放置与激活。

支持两种模式：

- 双人热座：两名玩家在同一设备轮流落子。
- 电脑对战：可选择执红先手或执白后手。电脑结合双生成树策略、金桥虚拟连接、强制威胁搜索、电阻网络排序、置换表和限时迭代加深。
- 白方电脑默认把金桥放在中央 `5,5`，红方封锁一侧后从另一侧接入。
- 电脑计算与界面一起打包为单一 Web 应用，直接在手机浏览器运行。

## 运行

```bash
npm install
npm run dev
```

测试与生产构建：

```bash
npm test
npm run build
```

## 规则

- 白方先放置一枚中立桥。红方不能使用；白方可在自己的回合花费一步将它接通。
- 随后红方先手，双方轮流在合法位置放置一枚连接块。
- 红方尝试连通棋盘上下两边，白方尝试连通左右两边。
- 任一方用自己的连接块形成完整闭环也立即获胜。
- 棋盘边缘不能作为闭环的一部分。
- 每个连接位只能容纳一枚棋块，但新棋块不必与已有路线相连。
